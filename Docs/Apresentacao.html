O que é o Lambda

Uma função que só existe quando alguém a chama. Você envia o código, a AWS executa quando chega um evento e você paga apenas pelo tempo de execução.

  • Não existe servidor para instalar, atualizar ou monitorar.
  • Cada chamada recebe um evento (um JSON) e devolve um resultado.
  • A AWS cuida de escalar: de nenhuma execução até muitas em paralelo.
Limites a conhecer: há um tempo máximo por execução e a primeira chamada depois de um período parado é um pouco mais lenta (partida a frio). Consulte os valores atuais na documentação da AWS.

Vantagens e casos de uso

Vantagens

  • Sem servidor para manter
  • Escala automática
  • Cobrança por uso (há camada gratuita)
  • Integra com S3, filas, agendamentos e API Gateway

Casos de uso

  • Processar um arquivo assim que ele chega no S3
  • Consumir mensagens de uma fila
  • Rotinas agendadas (relatório diário, limpeza)
  • Webhooks e APIs
Por que Delphi? Você reaproveita regras de negócio já escritas, com código compilado, rápido para iniciar e sem interpretador.

Como a biblioteca funciona

O Lambda não precisa conhecer a linguagem. Ele só precisa de um programa chamado bootstrap que converse com ele por HTTP (a Runtime API).

AWS LambdaRuntime API
↔
Seu executável Delphibootstrap (Linux 64 bits)
→
Sua funçãoregra de negócio

A biblioteca implementa o ciclo que o Lambda espera:

  1. O programa pergunta ao Lambda: "tem um evento para mim?"
  2. Recebe o evento em JSON.
  3. Chama a sua função Delphi.
  4. Devolve o resultado (ou o erro) e volta ao passo 1.

Se a sua função lançar uma exceção, ela é informada ao Lambda como erro da função e o programa segue atendendo as próximas chamadas.

Exemplo: calcular desconto

Um handler que não é HTTP: recebe um JSON com o valor e o tipo de cliente e devolve o total com desconto. Projeto Samples/DescontoLambda.

ClienteDesconto
vip10%
regular5%
qualquer outro0%

A função

function CalcularDesconto(const ARequest: TAWSLambda4DRequest;
  const AContext: TAWSLambda4DContext): TAWSLambda4DResponse;
var
  LEvento, LResultado: TJSONObject;
  LValor, LDesconto: Double;
  LCliente: string;
  LPercentual: Integer;
begin
  LEvento := TJSONObject.ParseJSONValue(ARequest.Body) as TJSONObject;
  try
    if LEvento = nil then
      raise EArgumentException.Create('O evento deve ser um JSON object.');
    if not LEvento.TryGetValue<Double>('valor', LValor) then
      raise EArgumentException.Create('O campo "valor" e obrigatorio.');
    if not LEvento.TryGetValue<string>('cliente', LCliente) then
      LCliente := '';
  finally
    LEvento.Free;
  end;

  LPercentual := PercentualDesconto(LCliente);
  LDesconto := RoundTo(LValor * LPercentual / 100, -2);

  LResultado := TJSONObject.Create;
  try
    LResultado.AddPair('desconto', TJSONNumber.Create(LDesconto));
    LResultado.AddPair('total', TJSONNumber.Create(RoundTo(LValor - LDesconto, -2)));
    Result := TAWSLambda4DResponse.Create;
    Result.Body := LResultado.ToJSON;
  finally
    LResultado.Free;
  end;
end;

Trecho resumido para caber na tela; o arquivo completo está no sample.

O programa principal

begin
  // Fora da Lambda: testa aqui, com um evento de exemplo.
  // Dentro da Lambda: entra no loop normal.
  if TAWSLambda4Runner.SelfHosted then
    TAWSLambda4Runner.RunLocal(CalcularDesconto, '{"valor":200,"cliente":"vip"}')
  else
    TAWSLambda4Runner.Run(CalcularDesconto);
end.

Entrada e saída

Evento

{"valor":200,"cliente":"vip"}

Resposta

{"valor":200.0,"cliente":"vip",
 "descontoPercentual":10,
 "desconto":20.0,"total":180.0}

Quando o evento é inválido

Se faltar o campo valor ou ele for negativo, a função lança uma exceção. O Lambda registra o erro da função e continua pronto para a próxima chamada:

Function.EArgumentException: O campo "valor" e obrigatorio.

Testando na minha máquina

Antes de enviar para a AWS, o mesmo executável roda no Windows (ou no Linux) contra um servidor local que imita a Runtime API.

  • SelfHosted é verdadeiro quando o programa não está dentro do Lambda.
  • RunLocal(função, evento) entrega um evento, executa a função e imprime a resposta no console.
  • Dentro do Lambda, a mesma linha chama Run, o loop de verdade.
[RunLocal] Response: {"valor":200.0,"cliente":"vip","descontoPercentual":10,"desconto":20.0,"total":180.0}
Mesmo código, dois ambientes: não é preciso mudar nada para publicar.

Compilar e publicar

  1. Compile o projeto para Linux 64 bits (precisa do SDK de Linux do Delphi).
  2. Renomeie o executável para bootstrap e compacte em um .zip.
  3. No console da AWS, crie a função Lambda com runtime personalizado (provided.al2023) e envie o zip.
  4. Use Test com o evento {"valor":200,"cliente":"vip"} e confira o resultado e o log no CloudWatch.
Dica: deixe a conta e o zip prontos antes de gravar, e mostre também um evento inválido para ver o erro sendo registrado.

E se essa função respondesse a uma requisição HTTP, como uma API REST?

Vamos transformar o handler em rotas, com GET, POST e parâmetros na URL, tudo dentro do Lambda:

LRouter := TAWSLambda4DHTTPRouter.New;
LRouter.Get('/ping',
  function(const ARequest: TAWSLambda4DHTTPRequest): TAWSLambda4DHTTPResponse
  begin
    Result := TAWSLambda4DHTTPResponse.Create;
    Result.StatusCode := 200;
    Result.SetBody('{"message":"pong"}');
  end);
